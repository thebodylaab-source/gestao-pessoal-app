Configurar Google Drive

Os seus dados ficam guardados num ficheiro gestao-pessoal.json no seu Google Drive e sincronizam entre computadores.

Como obter as credenciais (5 min)
1. Aceda a console.cloud.google.com
2. Crie um projeto (ex: "Gestão Pessoal")
3. Ative a Google Drive API
4. Credenciais → Criar → ID de cliente OAuth 2.0 → Aplicação Web
5. Adicione null em origens autorizadas (para ficheiros locais)
6. Credenciais → Criar → Chave de API

As credenciais ficam guardadas apenas no seu computador (localStorage).
