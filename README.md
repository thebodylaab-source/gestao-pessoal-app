# Gestão Pessoal

App privada em HTML/CSS/JavaScript para gerir finanças, tempo, investimentos, orçamento e créditos.

## Desenvolvimento

```powershell
npm.cmd install
npm.cmd run dev
```

## Build

```powershell
npm.cmd run build
```

## Deploy

O projeto está pronto para Vercel como site estático/Vite.
